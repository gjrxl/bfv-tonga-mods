# BFV Tonga MOD 合集

面向《战地风云 V》Tonga 私人测试环境的 MOD 合集。每个 MOD 单独维护，后续按目录加入其他项目。

**当前是实验版本，不是已全面验收的稳定版。** 原版游戏更新、其他 MOD 和服务器配置都可能影响结果；仅记录明确测过的行为。

## 使用

1. 使用自己的 Tonga 私人测试房间。作者环境：Frosty Mod Manager 1.0.6.3、BFV 数据版本（head）3564730；其他版本未验证。
2. 游戏退出后，在 Frosty 创建独立 Pack，导入需要的 `.fbmod` 并勾选。
3. 首次先每个包单独测试；正常后再同时启用这两个包。
4. 按现有可用的 Tonga／Frosty 启动流程进入自己的房间，再检查实际效果。
5. 出问题时退出游戏，取消相应 MOD 并重新启动，不要在运行中替换文件。

完整步骤见 [安装与回退](docs/INSTALL.md)，测试方法见 [测试范围与反馈](docs/TESTING.md)。不会指导关闭或绕过反作弊，也不保证官方联机环境兼容性。

## 兼容性与已知限制

- 这两个包的资源清单没有同名资源重叠，但尚未完成两包单独及组合的完整游戏验收。
- 旧版 PIAT 补弹、旧“突击兵跨兵种配备”和 Super Tonga 整合包可能修改相同资源，未完成兼容性验收，首次测试请勿叠加。
- “无限补给”不代表无须装填、无限射速或载具自动补弹，也不保证每种特殊配备都能补充。
- 配备按资源引用去重；同名但来自不同职业的条目可能重复。显示在菜单中不代表已经验证可装备、部署或使用。
- 文件可被 Frosty 读取、静态检查通过，与游戏中实际生效是不同的验证阶段。

## 校验与反馈

下载后可用仓库根目录或 Release 附件中的 `SHA256SUMS.txt` 校验 `.fbmod`；`manifest.json` 记录版本、大小与验证状态。已知变化见 [修改记录](CHANGELOG.md)。
