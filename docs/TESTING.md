# 测试范围与反馈

## 已有依据

- 图标版只新增图标与更新版本号；两个包共 177 项游戏资源的描述和压缩负载与上一版逐字节一致。使用 Frosty 原生读取器确认两款内嵌 PNG 均能解码为 256×256 图像；未操作管理器界面或新增游戏实测。
- 补给包：145 项资源，654 处声明范围内的标量修改；已有全对象比较及 Frosty 读取检查。用户本机反馈 PIAT／步兵补给有效，载具补给无效；载具本来不在包内。
- 配备包：32 个常规兵种配置、640 个配备引用追加。离线比较确认原有选项与默认值保留。部分菜单已有用户反馈；医疗配备及全部四兵种的游戏内使用未全部验收。
- 初始补给实测包含其他已启用包，尚未通过开／关单包对照独立归因。上述反馈不能扩大为所有武器、所有阵营、所有模式均有效。
- 两包资源表无同名项，不代表已经通过完整运行时兼容性验收。

## 建议的最小游戏验收

| 项目 | 操作 | 应记录的结果 |
| --- | --- | --- |
| 补给基线 | 关闭补给包，同一武器不取补给、不重生持续发射 | 原状态是否会耗尽 |
| PIAT 补给 | 单开补给包，不取补给、不重生，连续发射至少 10 发 | 能否继续装填／发射，备用弹药如何变化 |
| 其他弹药 | 分别测试榴弹步枪、手雷和常用配备 | 每种具体装备是否补充，不将 PIAT 结果类推 |
| 切枪／重生 | 切换武器后再用，再死亡重生检查 | 是否保持正常、是否出现异常弹药／卡装填 |
| 配备互通 | 单开互通包，四兵种各选一种跨职业配备 | 菜单显示、能装备、能部署、实际功能分别记录 |
| 医疗与烟雾 | 检查医疗包、医疗箱、烟雾发射器 | 治疗／放置／发射是否有效，不只检查图标 |
| 两包组合 | 前述单包正常后，两包同时启用 | 互通配备能否实际使用与持续补给 |

不要求一次测完所有内容。没有测过的项目保持“待验证”，不要仅凭菜单或静态检查标记为通过。
