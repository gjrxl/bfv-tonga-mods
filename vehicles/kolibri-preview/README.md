# 战地5 · 硫磺岛蜂鸟直升机尝鲜包 v0.1

来自《战地5》火线风暴的原生 FL 282“蜂鸟”，现在可以在硫磺岛开起来了。支持登机、飞行和第三人称，取消耗油；碰撞扣血已实测，限高仍然存在。当前是无机载武器的运输体验版，使用日军本部固定停车点生成。
