## 已知问题与临时办法

首次登机可能仍受地面载具范围限制，美日两边均有反馈：先下机，等标志变白后重登；如仍不正常，再召唤一架尝试。船上召唤可能卡入船体；遮挡落点、摧毁后名额释放和连续呼叫仍有异常。上述办法不等于问题已修复，详细内容以压缩包内用户编辑的注意事项为准。
